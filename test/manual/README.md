# Spike scripts, kept for reference

These six files came from the unified-stt spike. They are standalone
scripts run by hand (`python -X utf8 test/manual/bench.py`), not pytest
tests, and pytest executed their module bodies on collection -- which is
why they now live outside the collected tree.

They do not run as-is. Every one of them points at
`C:\PROJECTS\other-project\transcribe.cpp\samples\jfk.wav`, which is not on
this machine. Use `test/assets/` instead; those fixtures are generated by
`scripts/make-fixtures.mjs` and their transcripts are recorded in
`test/assets/manifest.json`.

The three `test_ws_*.py` scripts drive the SPIKE's protocol -- `config`,
client-minted `finalize`, client-driven `check_turn` -- none of which
exists in protocol v1 (plan.md 4.3). They are superseded by
`test/test_protocol_v1.py`. They are kept only because they document what
the spike actually did; do not "fix" them to match the new protocol, and
delete them once nothing references them.

`bench.py`, `test_engine_direct.py` and `test_turn_engine.py` still
exercise the engines directly and are the closest thing to a manual
smoke test for those.
